# 単元対応表と問題追加手順

## 対応の範囲

文部科学省「中学校学習指導要領（平成29年告示）」の主要内容を、アプリの練習用単元に整理した計画表です。公式資料の問題文を転載していません。

[学習指導要領・解説（文部科学省）](https://www.mext.go.jp/a_menu/shotou/new-cs/1384661.htm)

数学は学年別の4領域（A 数と式／B 図形／C 関数／D データの活用）に対応させています。英語の文法項目は中学校3年間の言語材料を学習順に配置した目安で、学習指導要領がこの学年配当を指定しているという意味ではありません。国語・社会も教科書や学校で順序が異なります。理科は第1・第2分野の主要内容を整理しています。

この表は全到達目標を評価するものではありません。英語の聞く・話す・書く活動、国語の発表・記述、実験・観察・作図などは選択式問題だけでは評価できません。基礎から入試までの完成版ではなく、未収録や基本問題だけの単元を明示して段階的に拡張する構造です。

## 今回の追加と検証

- 中1数学7単元に各25問、計175問を追加。計算だけでなく、作図の性質、図形の移動、空間の位置関係、相対度数などの基本も含みます。
- 中1英語10単元に各20問、計200問を追加。文法・語彙・短い英文の情報読解を扱います。
- 新規375問はアプリ向けのオリジナル。既存126問はID・内容を維持し、`difficulty: "basic"` のみ付加しました。
- 数値計算140問は `verification.expression` と安全な式パーサーで分数として正答を照合。残りの概念問題35問・英語200問は正答・誤答・解説を作成時に見直しています。外部の教科専門家による校閲は未実施です。自動検証は英語の意味・教育的妥当性を保証するものではありません。
- 全問題のID重複、選択肢重複、正解範囲、前提単元の存在・循環、旧126問の互換性をテスト。

## データの追加方法

1. `data/catalog.json` で対象単元を見つけます。新規単元なら、一意の `id` と `key`、学年、教科、名称、領域、前提単元を追加します。既存の `key` は復習の関連付けに使うため変更しないでください。
2. `file` に `questions/grade-N/教科slug/unit-NN.json` を指定し、`data/` 以下に配列形式のファイルを作成します。未収録は `file: null`。宣言されていないファイルは読み込みません。
3. 各問題の必須項目は `id`, `grade`, `subject`, `unit`, `difficulty`, `question`, `options`, `answer`, `explanation`, `prereq`。`answer` は0始まり、選択肢は4つで正解は1つ。難易度は `basic` / `standard` / `advanced`。
4. 新規IDは例 `math-g1-u06-026`。公開後にIDの付け替え・再利用をしないでください。既存の `q001`〜`q126` は固定。旧問題を別ファイルへ移動しても内容とIDは維持します。
5. `prereq` は `教科|学年|単元名` の配列。存在し、問題が収録された単元だけを指定し、循環を作らないでください。
6. `python3 -m unittest discover -s tests -v`、`python3 scripts/prepare_site.py`、`node tests/browser.cjs` を実行します。ブラウザテストはPlaywrightが必要です。
7. PWAの全問題キャッシュ更新のため `sw.js` のリリース名を更新し、オンラインとオフラインを確認します。
8. 新規ブランチからPRを作成します。`main` へのマージ後にのみ公開デプロイされます。PRのチェックは公開しません。

## 旧記録・公開ファイル

`manabi-v2-progress`、データversion 2、バックアップ形式manabi-v2を維持しています。`attempts` と `review` はIDで参照するため、以前間違えた問題は同じ内容に結び付きます。ユーザーの学習記録を問題ファイルに含めないでください。

ルートの `questions.json` は旧クライアントの更新移行用として126問を変更せず残します。新アプリはこのファイルを使わず、catalogと単元別JSONを読み込みます。新規問題は必ず分割ファイルに追加してください。

配信は `scripts/prepare_site.py` の許可されたアプリ資産のみ。個人情報・バックアップ・テスト結果・ZIP・秘密情報はコミットも公開もしないでください。テストの学習記録は架空のデータで、ブラウザの一時コンテキストだけに保存します。
